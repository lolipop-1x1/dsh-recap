# DSH Recap · 会话回顾

**回来，就能接着做。** 在 DeepSeek Harness 里，用一小段回顾看清正在做什么、已经完成什么，以及下一步是什么。

## 不必从头翻一遍对话

离开一会儿，再回来面对长对话时，执行 `/recap`，就能看到当前任务和进展的简短回顾。

![功能演示：用简短回顾接上便签应用的开发进度](docs/assets/recap-demo.png)

_功能示意图，使用虚构内容演示回顾流程。_

- **手动查看，也可闲置时自动出现。** 随时调用命令；当前可见会话默认在 3 分钟无操作后回顾。
- **简短，长内容可展开。** 默认目标约 160 字符，最多预览三行，支持展开全文。
- **模型自己选。** 跟随主会话模型，也可选择已配置的其他模型来控制用量。
- **继续工作，不用等。** 后台生成，重复请求合并；失败时保留已有回顾，并提供重试入口。

## 快速开始

### 1. 从 GitHub 安装

在 Harness 左侧打开「**插件**」，点击「**添加插件**」，在「包名或地址」中粘贴：

```text
https://github.com/lolipop-1x1/dsh-recap
```

点击「**安装**」。如果提示需要运行构建脚本，确认来源及列出的脚本后，选择允许并重试；GitHub 安装需要从源码构建插件。

安装完成后，按页面提示重启 Harness（如需要），再刷新浏览器。如果已有其他插件占用 `/recap`，先停用旧插件。

### 2. 生成第一条回顾

打开一个已有工作内容的会话，发送：

```text
/recap
```

需要选择模型或调整自动回顾时，发送 `/recap settings`，或打开「**设置 → 会话回顾**」。修改会自动保存。

## 命令

| 命令              | 作用                                             |
| ----------------- | ------------------------------------------------ |
| `/recap`          | 生成回顾；资料未变化时复用已有结果。             |
| `/recap refresh`  | 跳过缓存，重新生成。                             |
| `/recap hide`     | 隐藏回顾并暂停本会话自动回顾，直到再次手动请求。 |
| `/recap status`   | 只查看状态，不生成或恢复已隐藏的回顾。           |
| `/recap settings` | 直接打开回顾设置弹窗。                           |
| `/recap help`     | 查看命令帮助。                                   |

提交命令后输入立即清空，生成在后台继续；随后输入的新草稿不会被改动。手动回顾显示在对应命令的位置，打开设置或查询状态不会将其挪走。

## 按你的习惯设置

执行 `/recap settings`，直接在当前会话打开设置，调整触发方式；修改会自动保存。

![回顾设置示意：自动保存、闲置触发、模型选择和摘要长度](docs/assets/recap-settings-demo.png)

_设置功能示意，默认值和用量选项见下表。_

| 设置     | 默认行为                                               |
| -------- | ------------------------------------------------------ |
| 回顾模型 | 跟随当前会话，也可选择已配置的其他模型                 |
| 回顾语言 | 跟随界面，也可指定中文或英文                           |
| 自动回顾 | 至少完成 3 个有内容的轮次后，闲置 3 分钟触发           |
| 目标长度 | 约 160 字符，保留完整句子                              |
| 生成预算 | 最多 12 条最近消息、6,000 个素材字符、512 个输出 token |

这些预算限制输入材料和输出上限，不代表每次固定消耗这么多。高级选项默认折叠，完整字段和旧版兼容说明见[配置说明](docs/配置说明.md)。

打开或切换会话不会立即生成。键盘、点击和滚动会重置闲置计时，主 Agent 忙碌时等待其空闲。已完成的回顾不会因页面失焦自行消失；继续对话、刷新或关闭页面后隐藏。刷新一个标签页不会清除其他标签页的回顾。
