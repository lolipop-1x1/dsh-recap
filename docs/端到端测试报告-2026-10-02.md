## 已修复缺陷

1. 任意标签页关闭都清空共享 `displayTurn`，会误隐藏另一个仍可见页面的摘要。仅在没有其他可见页面时清除；增加双标签关闭顺序断言。
2. 手动生成中刷新，迟到结果重新显示。最后可见页面关闭且已有展示任务时取消任务，迟到结果不再提交；增加关闭、重开、延迟完成的时序回归。
3. 事实降级不检查 `goalPhase`，将完成目标称为当前任务。完成目标明确标为已完成，保留独立的进行中待办与下一步；增加中英文断言。

复现命令：`npx vitest run tests/engine.test.ts tests/core.test.ts`。新增断言在修复前失败，在修复后通过。

## 限制与后续验收

本轮三项修复属于 Host 代码，当前已构建，真实实例需要重新加载后再进行针对性验收；不能把受控调度回归写成已部署验收。全新 profile 安装、多操作系统、多版本、长时间运行、全部真实模型和复杂业务摘要质量未穷尽验证。浏览器关闭请求的可靠性、后台标签超过心跳租约后的交互语义还需专项验证。

产品合理性问题单独记录在[产品体验评估](产品体验评估.md)，未因旧设计文档写过就认定合理，也未未经确认实施产品改版。
