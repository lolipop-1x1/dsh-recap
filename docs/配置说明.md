# 配置说明 / Configuration

由 `npm run docs:config` 从唯一字段定义自动生成。菜单显示语言跟随 Harness；回顾输出语言可单独设置。

| 字段                  | 中文 / English                                        | 默认值     | 类型与范围             | 说明                                             |
| --------------------- | ----------------------------------------------------- | ---------- | ---------------------- | ------------------------------------------------ |
| `autoEnabled`         | 自动回顾总开关 / Automatic recaps                     | `true`     | boolean                | 不影响手动 /recap。                              |
| `onCommand`           | 启用 /recap 命令 / Enable /recap command              | `true`     | boolean                | —                                                |
| `onIdle`              | 当前会话闲置时回顾 / Recap while idle                 | `true`     | boolean                | —                                                |
| `idleMinutes`         | 几分钟没操作后回顾 / Idle threshold (minutes)         | `3`        | 0.1–1440               | 只在当前正在展示的会话中触发；切换会话重新计时。 |
| `minTurns`            | 自动回顾的最少完成轮次 / Minimum completed turns      | `3`        | 0–1000                 | —                                                |
| `mode`                | 生成方式 / Generation mode                            | `"hybrid"` | hybrid / deterministic | hybrid 使用模型；deterministic 只整理事实。      |
| `provider`            | 服务商路由 / Provider route                           | `""`       | text                   | 与模型同时留空时跟随当前会话。                   |
| `model`               | 模型 / Model                                          | `""`       | text                   | —                                                |
| `language`            | 回顾语言 / Recap language                             | `"auto"`   | auto / zh / en         | auto 跟随 Harness 界面语言。                     |
| `maxTokens`           | 输出 token 上限 / Maximum output tokens               | `512`      | 64–4096                | —                                                |
| `maxSourceMessages`   | 最近消息条数上限 / Maximum recent messages            | `12`       | 1–80                   | —                                                |
| `maxSourceChars`      | 输入素材字符上限 / Maximum source characters          | `6000`     | 1000–64000             | —                                                |
| `timeoutSeconds`      | 生成超时秒数 / Generation timeout (seconds)           | `20`       | 2–120                  | —                                                |
| `oneLineMaxChars`     | 回顾目标字数 / Target recap length                    | `160`      | 80–1000                | 默认约 160 字符，保留完整句子；超过三行可展开。  |
| `cacheTtlTurns`       | 自动回顾缓存轮次 / Automatic cache window (turns)     | `0`        | 0–30                   | 旧缓存标记过期；0 表示资料变化即重新生成。       |
| `autoCooldownSeconds` | 自动调用最短间隔（秒） / Automatic cooldown (seconds) | `30`       | 0–3600                 | —                                                |
| `maxConcurrent`       | 最多同时生成的会话数 / Maximum concurrent generations | `2`        | 1–8                    | —                                                |
| `maxSessions`         | 最多缓存会话数 / Maximum cached sessions              | `100`      | 5–1000                 | —                                                |
| `injectToModel`       | 将回顾注入主模型 / Inject recap into main model       | `false`    | boolean                | 默认关闭。开启会增加模型上下文。                 |

所有设置通过原生 volatile 配置持久化。保存必须携带读取时的 revision；冲突时保留草稿，不做静默覆盖。服务商与模型必须同时填写或同时留空。

自动总开关不影响手动命令；`onCommand` 是单独的命令开关。自动回顾只在当前可见会话闲置时触发，打开或切换会话只重新计时。调度设置（如闲置阈值和并发数）更改不会清除已有回顾或使缓存过期；关闭自动回顾或闲置触发只取消没有手动请求等待的自动任务；已经合并的手动请求继续执行。影响回顾内容的设置（模型、语言、预算、超时和目标字数等）更改会取消旧任务，保留已有回顾并标记「较早回顾」，下次请求按新配置重新生成。

缓存的轮次窗口只控制自动复用；资料变化后默认重新生成。模型生成失败、超时或返回不完整内容时保留已有摘要并显示错误，不自动改用事实回顾；没有旧摘要时只显示失败提示。手动 `/recap refresh` 跳过缓存重新尝试。回顾默认展示三行，展开后显示全文；目标字数用于提示模型生成长度，不硬截断正常结果。

原生设置服务缺失时，插件仍可提供回顾命令；自定义设置页为只读。已有的闲置设置继续生效。旧 `includeStats`、`onAway`、`awayMinutes`、`onResume`、`onCompact`、`onTurnEnd` 字段仅兼容读取并忽略。
